#  期末報告：

1.  專題報告文件(word檔)
2.  口頭報告投影片: 重點式呈現。
3.  展示影片：3–5 分鐘，展示系統操作或成果。
4.  實作部分：需附元件連接線路圖與程式碼。
5.  程式碼附錄：可附主要模組或 GitHub 連結。 

## 報告文件格式

-   檔案類型：Word（.docx）
-   字型與排版：標楷體或 Times New Roman，12pt
-   頁面設定：A4，左右邊界 2.5 cm，上下邊界 2.5 cm
-   封面內容：
    -   專題名稱
    -   組員姓名與學號
    -   指導老師
    -   系級與學期
    -   日期
-   內容結構
    |  | 章節 | 說明 |
    | --- | --- | --- |
    | 1 | 動機與目的 | 說明研究或開發的背景與目標。 |
    | 2 | 文獻探討 | 引用相關研究、技術或系統，建立理論基礎。 |
    | 3 | 系統架構 | 以方塊圖或流程圖說明系統設計。 |
    | 4 | 實作內容 | 包含硬體連接圖、程式碼片段、模組功能說明。 |
    | 5 | 測試與結果 | 展示系統運作成果、效能分析或測試數據。 |
    | 6 | 結論與未來方向 | 總結成果與後續改進建議。 |

## 評分標準

| 評分面向 | 內容 |
| --- | --- |
| 技術深度 | 系統設計與程式實作的完整度 |
| 創新性 | 題目與方法的新穎程度 |
| 應用性 | 是否能實際應用或延伸 |
| 表達能力 | 報告與簡報的清晰度 |
| 團隊合作 | 分工與協作成果 |
